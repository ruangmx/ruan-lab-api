# 🚀 Ruan Lab API

Esta é uma API técnica desenvolvida para estudos de backend, focada em entender o funcionamento de rotas, servidores Node.js e integração com o GitHub.

## 🛠 Tecnologias Utilizadas
* **Node.js**: Ambiente de execução para o JavaScript no servidor.
* **Express**: Framework para criação das rotas e gerenciamento das requisições.
* **Git/GitHub**: Controle de versão e deploy do código.

## 📌 Funcionalidades
- [x] Servidor básico rodando na porta 3000.
- [x] Rota de teste (`/hello`) retornando JSON.
- [x] Configuração de `.gitignore` para segurança do projeto.
